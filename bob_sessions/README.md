# IBM Bob task sessions

Evidence of IBM Bob 2.0 usage for the IBM Bob 2.0 Hackathon, as required by the submission rules.
Each team member adds their own files here.

For every Bob session:

1. In IBM Bob IDE, open the task history and **export** it (Markdown).
2. Take a screenshot of the task's **consumption summary** (Bobcoins used).
3. Save both here using the naming below, then commit.

```
bob_sessions/
  <member>/
    01-onboarding-init-ask.md
    01-onboarding-init-ask.png
    02-review-findings.md
    02-review-findings.png
    ...
```

| # | Session | Bob feature |
|---|---------|-------------|
| 01 | `/init`, then trace how a failing test becomes a repair attempt | Ask mode, parallel explore subagents |
| 02 | `/review` on the repair loop, sandbox and deploy code; fix confirmed findings | Bob Findings panel, Code mode |
| 03 | Plan the Continue in IBM Bob handoff from our docs | Plan mode, document understanding |
| 04 | Build the handoff end to end | Agent mode, parallel tool calls |
| 05 | Write tests for the handoff | General subagent |
